# ISEKAI

A 3D action RPG for the web (three.js), played in landscape on phones and PC. Jasper, a game tester, wakes up inside the unfinished world of Aster and fixes it with PATCH. Four zones, four bosses, multiple endings, and a New Game+ where Princess Victory plays her own story.

Play: https://jasperefe.github.io/Isekai/

- Full project handoff (story, code map, difficulty, ads, how to build and test): [docs/HANDOFF.md](docs/HANDOFF.md)
- Run locally: `python3 -m http.server 8766`, then open http://localhost:8766/
- Playgama upload: `bash tools/build_playgama.sh` makes `dist/ISEKAI_playgama.zip`
